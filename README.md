Bu projenin amacı günlük hayatta planlamış olduğumuz etkinliklerin yapılıp yapılmadığını kontrol etmektir.
Projenin Özelliklerini ise şu şekilde açıklayabiliriz;
Html, Css ve Java Script Frontend(ÖnYüz) Kısmına Hitap eden diller kullanılmıştır.
Projenin İçeriği ise; Ekleme ve Silme özellikleri olan istenildiği kadar eylem eklenilen ve yapılacaklar listesinden çıkartılmak istenenleri silinebilen bir projedir.
